# Python Projects

A curated collection of Python projects created while progressing through Python fundamentals, problem solving, Object-Oriented Programming, GUI development, file handling, and basic data analysis.

These projects were primarily built while working through the **100 Days of Code: Python** course and related practice.

The projects are kept reasonably close to the implementations I created at each stage of learning. I later made small cleanup changes such as fixing bugs, improving naming and readability, and removing unnecessary development files while preserving the original learning-level approach.

## Running a Project

Open the folder for the project you want to run and execute:

```bash
python main.py
```

Some projects require additional files such as CSV datasets, images, or supporting Python modules. These are included inside their respective project folders.

External dependencies can be installed with:

```bash
pip install -r requirements.txt
```
