# Secret Auction

A simple command-line auction program built while learning Python dictionaries and loops.

The program allows multiple users to place bids for an item, stores each bid, and determines the highest bidder at the end.

## Concepts Practiced

- Dictionaries
- `while` loops
- `for` loops
- `if / else`
- User input
- Comparing values
- Tracking the highest value
- Basic program flow

## How It Works

The program:

- Asks whether the user wants to participate in an auction
- Lets the user enter the item being auctioned
- Collects names and bid amounts from multiple bidders
- Hides previous bids before the next bidder enters their details
- Finds the highest bid
- Displays the winner and final bid amount

## How to Run

```bash
python main.py
```

Make sure the following files are in the same folder:

- `main.py`
- `art.py`

Then follow the prompts in the terminal and enter the bids for each participant.
