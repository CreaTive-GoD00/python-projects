# Etch-a-Sketch

An interactive drawing program built using Python's Turtle graphics module.

The user controls a Turtle with the keyboard and can move forward, backward, rotate, and clear the drawing screen.

## Controls

- `W` - Move forward
- `S` - Move backward
- `A` - Turn left
- `D` - Turn right
- `C` - Clear the drawing

## Concepts Practiced

- Turtle graphics
- Functions
- Keyboard event handling
- `screen.listen()`
- `onkeypress()`
- Turtle movement
- Turtle headings
- Interactive program control

## How It Works

The program listens for keyboard input and connects each key to a movement function.

As the Turtle moves around the screen, it draws a line and allows the user to create their own shapes or sketches.

Pressing `C` resets the Turtle and clears the drawing.

## How to Run

```bash
python main.py
```

A Turtle graphics window will open.

Use the keyboard controls to draw on the screen, then click the window when you want to close the program.
