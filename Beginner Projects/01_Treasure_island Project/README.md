# Treasure Island

A small text-based adventure game built while learning Python fundamentals.

The player makes a series of choices while trying to reach a hidden treasure. Each decision changes the path of the story, and most of the choices end... badly. 😅

## Concepts Practiced

- `input()`
- Conditional statements
- Nested `if / elif / else`
- String methods such as `.upper()` and `.strip()`
- Basic program flow
- Multi-line ASCII art

## How to Run

```bash
python main.py
```

Then follow the prompts in the terminal and choose your path.

## About This Project

This was one of my early Python projects from the **100 Days of Code** course.

The code is intentionally kept close to the level I was at when I originally built it, with only small cleanup and readability improvements.

## Example Choices

Some possible choices include:

- Left / Right
- Wait / Swim
- Plane / Tunnel

There may or may not be a happy ending. 😂
