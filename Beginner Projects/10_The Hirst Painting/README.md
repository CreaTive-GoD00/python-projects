# Hirst-Style Dot Painting

A colorful dot painting created using Python's Turtle graphics module.

The program draws a grid of randomly colored dots using RGB color values and Turtle movement. It was built while learning how to work with Turtle graphics, functions, loops, and coordinate-based movement.

## Concepts Practiced

- Turtle graphics
- Functions
- `for` loops
- Random selection
- RGB colors
- Tuples
- Lists
- Turtle headings and movement
- Pen control
- Repeated drawing patterns

## How It Works

The program:

- Moves the Turtle to a starting position
- Selects random RGB colors from a predefined color list
- Draws rows of colored dots
- Moves between rows using Turtle headings
- Alternates drawing direction to create a grid pattern

## How to Run

```bash
python main.py
```

A Turtle graphics window will open and automatically create the dot painting.

Click the graphics window when the drawing is complete to close the program.
