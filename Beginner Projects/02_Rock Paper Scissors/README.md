# Rock Paper Scissors

A simple command-line Rock Paper Scissors game built while learning Python fundamentals.

The player chooses Rock, Paper, or Scissors, while the computer randomly selects its own option. The game then compares both choices and displays the result.

## Concepts Practiced

- Variables
- User input
- `if / elif / else`
- Tuples
- Indexing
- Random number generation
- Boolean conditions
- Basic game logic
- ASCII art

## How to Run

```bash
python main.py
```

Choose:

- `0` for Rock
- `1` for Paper
- `2` for Scissors

The computer will randomly choose its option and the winner will be displayed.
