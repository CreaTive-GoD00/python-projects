# Caesar Cipher

A command-line Caesar Cipher program built while learning Python functions and string manipulation.

The program can encode or decode a message by shifting letters through the alphabet using a user-provided shift value.

## Concepts Practiced

- Functions
- Function parameters and arguments
- `for` loops
- `while` loops
- Lists
- String manipulation
- User input
- Modular arithmetic
- Imports
- Conditional logic

## Features

- Encode messages
- Decode messages
- Preserve spaces, numbers, and symbols
- Support shift values larger than the alphabet length
- Run multiple cipher operations without restarting the program

## How to Run

```bash
python main.py
```

Choose whether you want to encode or decode a message, enter the text and shift amount, and the program will display the result.

Make sure the following files are in the same folder:

- `main.py`
- `art.py`
