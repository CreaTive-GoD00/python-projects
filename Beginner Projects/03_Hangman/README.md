# Hangman

A command-line Hangman game built while learning Python fundamentals.

The player guesses letters one at a time while trying to reveal a randomly selected word before running out of lives.

## Concepts Practiced

- `while` loops
- `for` loops
- Lists
- String building
- Conditional logic
- Imports
- Random selection
- Tracking game state
- User input

## How to Run

```bash
python main.py
```

Make sure the following files are in the same folder:

- `main.py`
- `hangman_words.py`
- `hangman_art.py`

Then guess one letter at a time until you either complete the word or run out of lives.
