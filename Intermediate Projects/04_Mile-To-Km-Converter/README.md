# Mile to Km Converter

A simple desktop GUI application built using Python's Tkinter library.

The program allows the user to enter a distance in miles and converts it into kilometers when the Calculate button is pressed.

## Concepts Practiced

- Tkinter
- GUI windows
- Labels
- Entry fields
- Buttons
- Grid layout
- Callback functions
- Reading user input
- Updating widget values
- Basic unit conversion

## How It Works

The user enters a distance in miles.

When the Calculate button is clicked:

1. The value is read from the input field
2. The miles value is multiplied by `1.609`
3. The result is displayed in kilometers

## How to Run

```bash
python main.py
```

A small Tkinter window will open.

Enter a number in the Miles field and press `Calculate` to see the converted distance.
